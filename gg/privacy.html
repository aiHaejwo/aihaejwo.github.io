신화각 : 핀볼 바운스 디펜스 웹 게임 개인정보처리방침

시행일: 2026년 10월 20일 · 운영자: aiHaejwo

게임 기록과 설정

회원가입 없이 플레이할 수 있습니다. 골드, 신화석, 영웅 강화, 최고 웨이브, 튜토리얼 완료 여부와 설정은 브라우저의 로컬 저장소에 저장합니다. 운영자 서버로 전송하지 않으며, 다른 기기로 동기화되지 않습니다. 브라우저의 사이트 데이터를 삭제하면 기록도 삭제됩니다.

원스토어 연결

원스토어 Web SDK를 이용해 게임 초기화, 로딩, 일시정지, 재개, 종료와 외부 링크 열기를 처리합니다. 초기화 시 원스토어가 제공하는 게임별 가명 ID, 언어, 무음 모드와 화면 여백 정보 중 무음 모드와 화면 여백만 실행에 사용합니다. 가명 ID를 게임 서버로 전송하거나 저장하지 않습니다. 원스토어에 로딩 진행률과 시작 상태를 전달하며, 원스토어 자체 서비스의 개인정보 처리는 원스토어의 개인정보처리방침을 따릅니다.

호스팅과 네트워크

이 게임은 GitHub Pages에서 제공하며, 원스토어 CDN에서 SDK를 불러옵니다. 게임 파일과 SDK를 내려받는 과정에서 IP 주소, 브라우저 정보, 방문 URL, 요청 시각 등 일반적인 요청 정보가 해당 서비스에 전달될 수 있습니다. GitHub는 서비스 운영과 보안 목적으로 접속 정보를 처리하며 미국을 포함한 여러 국가에서 데이터를 처리할 수 있습니다. 보존 기간과 처리에 관한 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요. 게임 진행 기록은 이러한 네트워크 요청에 포함되지 않습니다.

광고와 결제

이 웹 버전은 원스토어 Web SDK의 전면 광고와 선택형 보상 광고를 지원합니다. 광고 ID 발급과 서버 연결이 완료되면 원스토어 앱 안에서 제공합니다. 현금 결제는 없습니다. 광고 제공 과정의 정보 처리는 원스토어 및 광고 제공사의 정책을 따릅니다. 별도로 배포되는 Android·iOS 앱은 Google AdMob을 사용합니다.

보상형 광고는 시청 확인을 위해 무작위 보상 요청 ID, 일회용 확인 토큰, 생성·만료 시각, 시청 확인과 지급 여부를 gg 전용 Cloudflare 서버에 최대 24시간 보관합니다. 게임의 재화 잔액이나 전체 진행 기록, 원스토어 가명 ID는 이 서버로 보내지 않습니다. 서명이 검증된 원스토어 완료 통지가 있어야 보상이 지급됩니다. Cloudflare에는 접속 IP와 일반적인 네트워크 요청 정보가 전달되며, 미국을 포함한 서비스 제공 지역에서 처리될 수 있습니다. 인프라의 보안·백업 보관은 Cloudflare 개인정보처리방침을 따릅니다.
