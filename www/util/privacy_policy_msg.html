1. 개요 및 개인정보의 처리 목적

'다시봄'(이하 '앱')은 사용자가 놓치거나 삭제된 메신저 알림을 기기 내에서 안전하게 다시 확인하고 백업할 수 있도록 돕는 로컬 유틸리티 소프트웨어입니다.

앱은 오직 사용자가 지정한 메신저의 알림 히스토리를 사용자 본인의 스마트폰에 영구 보존하여 보여주는 목적으로만 동작하며, 상업적 마케팅 또는 광고 타겟팅 등의 목적으로 개인정보를 활용하지 않습니다.

2. 수집 및 처리하는 정보의 항목

본 앱이 사용자의 스마트폰 로컬 저장소(SQLite DB 및 내부 샌드박스)에 저장하는 데이터 항목은 다음과 같습니다:

구분 처리 항목 처리 목적 저장 위치
알림 메타데이터 패키지명, 발신자 이름, 수신 일시, 읽음 여부 발신자별 대화 목록 분류 및 타임라인 정렬 기기 내부 SQLite DB (외부 접근 불가)
메시지 내용 수신된 텍스트 메시지 내용 앱 내 알림 다시보기 기능 제공 기기 내부 SQLite DB
알림 사진/이미지 알림에 포함된 사진 미리보기 비트맵 대화방 내 고화질 사진 다시보기 제공 기기 내부 앱 전용 디렉터리 (샌드박스)

3. 안드로이드 시스템 특수 권한 사용 안내

앱의 핵심 기능을 수행하기 위해 다음과 같은 안드로이드 권한을 사용합니다:

  • 알림 접근 권한 (BIND_NOTIFICATION_LISTENER_SERVICE):
    사용자가 활성화한 메신저(카카오톡 등)에서 상태 표시줄에 띄우는 알림 텍스트와 사진 데이터를 감지하여 로컬 데이터베이스에 저장하기 위한 필수 권한입니다. 본 권한으로 읽어 들인 모든 정보는 외부 서버로 유출되지 않고 스마트폰 내부에만 머뭅니다.
  • 배터리 최적화 예외 요청 (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS):
    화면이 꺼져 있거나 백그라운드 상태에서도 중요한 알림이 누락 없이 기록될 수 있도록 백그라운드 프로세스 유지를 위해 요청됩니다.
  • 부팅 완료 수신 (RECEIVE_BOOT_COMPLETED):
    스마트폰 재부팅 후에도 백업 서비스가 자동으로 안전하게 재가동되도록 하기 위해 사용됩니다.

4. 외부 전송 및 제3자 제공 금지 원칙

본 앱은 어떠한 형태의 원격 백엔드 서버도 보유하거나 운영하지 않습니다.

  • 수집된 모든 메시지 및 사진은 100% 사용자의 휴대폰 내부 암호화 샌드박스에만 기록됩니다.
  • Google Analytics, Firebase, 광고 SDK, 데이터 브로커 등 외부 트래킹 라이브러리를 일절 탑재하지 않았습니다.
  • 따라서 제3자(Third-party)에게 개인정보가 제공되거나 위탁되는 일은 절대 발생하지 않습니다.

  • 자동 보관 기간 관리: 사용자는 앱 내 [설정] ➔ [보관 기간] 메뉴에서 7일, 14일, 30일, 60일, 90일 또는 무제한을 선택할 수 있으며, 설정된 기한이 지난 알림과 이미지 파일은 기기 내에서 자동으로 영구 파기됩니다.
  • 수동 즉시 파기: 앱 내 [설정] ➔ [전체 데이터 삭제] 버튼을 터치하면 로컬 DB와 모든 이미지 파일이 즉각 영구 삭제됩니다.
